# Online Voting System 🗳️

A simple and interactive **Online Voting System** built using **HTML, CSS, and JavaScript**.
This project allows users to register, login, cast their vote securely, and view election results instantly.

---

## 🚀 Features

* 👤 User Registration & Login
* 🔐 Authentication System using LocalStorage
* 🗳️ One User = One Vote
* 📊 Live Election Results
* 🎨 Clean and Responsive UI
* 🚪 Logout Functionality
* 💾 Data stored using Browser LocalStorage

---

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript (Vanilla JS)**
* **LocalStorage API**

## ⚙️ How It Works

1. Users register with a username and password.
2. Registered users can login securely.
3. After login, users can cast a vote for their preferred candidate.
4. Once voted, users cannot vote again.
5. Results are displayed immediately after voting.

## 🔒 Voting Rules

* Each user can vote only once.
* Duplicate usernames are not allowed.
* Vote data is stored locally in the browser.
